# PNG压缩工具

Windows PNG 批量压缩工具，提供本地压缩和 Tinify 云端压缩

## 下载安装

前往 [最新版本](https://github.com/Zy1raxxoo/png-compressor-releases/releases/latest)，下载 `PNGCompressorSetup-版本号.exe` 并安装

从 1.2.0 起，软件支持自动检查更新，也可以点击主界面的“检查更新”
更新说明和下载进度均在软件内部显示，校验完成后点击“安装并重启”即可更新
更新前请完成任务，并保存或清空待保存结果

## 自己申请云端压缩 API Key

本地压缩无需注册账号或填写密钥，使用云端压缩时需要申请自己的 Tinify API Key
软件不内置开发者的密钥，每位用户使用自己账号的压缩额度

1. 打开 [Tinify 官方 API 申请页面](https://tinify.com/developers)，找到 **Get your API key** 区域
2. 填写姓名 **Name** 和常用邮箱 **Email Address**，点击 **Create API key**，按页面提示完成注册
3. 打开邮箱，找到 Tinify 发来的激活邮件，点击邮件中的激活按钮，进入账号后台；没有收到时先检查垃圾邮件文件夹
4. 在 [API 管理页面](https://tinify.com/dashboard/api) 找到并复制自己的 **API Key**，这是密钥字符串，不是邮箱或网页地址
5. 打开软件的“设置”，将完整密钥粘贴到 **Tinify API Key** 输入框，点击“验证连接”，成功后保存设置
6. 回到主界面，将压缩方式切换为“Tinify 云端压缩”，即可添加图片并开始压缩

### 免费额度与常见问题

截至 2026 年 10 月，Tinify 官方提供每月 **500 次免费 API 压缩**，申请免费额度无需绑定付款方式，后续政策以 [官方页面](https://tinify.com/developers) 为准
本软件会逐轮尝试压缩，同一张图片可能消耗多次额度，因此 500 次额度不一定对应 500 张图片
当月用量可在软件主界面或 Tinify 的 API 管理页面查看

- 提示密钥无效：重新复制完整 API Key，并在设置中验证和保存
- 提示额度耗尽：先切换为本地压缩，等待额度恢复，或自行在 Tinify 官方管理页面了解付费方案
- 验证连接失败：确认网络能访问 Tinify，稍后再试

API Key 属于个人账号凭据，请勿将它公开到 GitHub 或分享给其他人
密钥只保存在当前 Windows 用户的本机加密设置中，软件更新会保留已有设置

## 软件内更新

启动后软件会自动检查新版，也可以手动点击“检查更新”
发现新版后，在软件内下载并等待校验完成，再点击“安装并重启”
本仓库用于分发安装包和软件内更新信息，联网更新需要能够访问 GitHub
